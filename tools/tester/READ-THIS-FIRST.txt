Modeled Threads - please test on Inventor 2025 or 2026
=======================================================

Thank you. This checks whether the add-in that works on Inventor 2027 also
works on yours, and leaves it installed so you can use it afterwards.

You need Inventor 2025 or 2026 on Windows 10 or 11, 64-bit. No administrator
rights. About ten minutes, most of it waiting.


What this does to your machine
------------------------------

It installs the add-in for your Windows account only:

  %APPDATA%\Autodesk\ApplicationPlugins\ModeledThreads.bundle

Nothing goes into Program Files, no admin rights are used, and nothing else is
changed. The add-in stays installed afterwards so you can keep using it. The
last section says how to remove it.


Step 1 - unblock the zip before extracting
------------------------------------------

Windows marks files that arrived from elsewhere, and it will silently refuse to
load the add-in if the DLL stays marked. So:

  1. Save the zip somewhere like your Downloads folder.
  2. Right-click the zip, choose Properties, tick "Unblock", click OK.
  3. Right-click again, Extract All.
  4. Work in the extracted folder, not inside the zip.

If you skip this the add-in will not appear, and Inventor gives no reason.


Step 2 - close Inventor, then double-click START-HERE.bat
---------------------------------------------------------

That one file does the rest, in this order:

  1. It asks you to close Inventor, if it is open, because the add-in cannot be
     copied while Inventor holds it. Save your work first.
  2. It installs the add-in and prints where it went.
  3. It starts Inventor and waits until it is ready.
  4. It asks you to try the add-in by hand (see below), and waits for Enter.
  5. It runs 109 automated checks, which takes two to four minutes.
  6. It tells you the add-in is installed and will be there next time.

If it asks "Add-in Manager Security Alert" the first time Inventor starts,
click "Launch Add-in Manager", pick "Modeled Threads", click "Unblock", OK.
That is once per user.


What to look at by hand
-----------------------

  1. Open a part with a shaft or a plain hole. A copy of a real part is fine;
     do not test on work you need.
  2. Select the cylindrical face, then "Modeled Threads" > "Create Thread".
     If the tab shows a single small "Threads" button, the ribbon is in its
     collapsed display mode: double-click any ribbon tab to expand it. That is
     Inventor's setting, not the add-in's.
  3. The dialog fills itself in for the face. The size box should spell out the
     pitch, for example M10x1.5 rather than a bare M10. Note what it shows.
  4. Press "Create Thread". A real thread is cut into the solid; look at it
     close up. It should have a proper profile, not a painted texture.
  5. Double-click the thread node in the browser, or use "Edit Thread". The
     dialog should open on that thread, same size, ready to change.
  6. Close the part without saving.

Anything odd is worth reporting: a crash, an error box, a thread in the wrong
place, a damaged face, or a size box showing a bare M10.


What good looks like
--------------------

The automated checks end with:

  ALL 109 CHECKS PASSED

and then:

  RESULT: every check passed on this Inventor.

If instead it says some checks failed, the lines marked FAIL say which. That is
exactly the sort of thing this test exists to find, so send it anyway.


Step 3 - send back
------------------

Send the newest file in the "report" folder. It is a text file containing:

  - your Windows and Inventor version
  - the version of the add-in that was installed
  - the check results
  - the last part of the add-in's log

If the folder also has a .log file, send that too. Nothing else is collected,
and no model geometry leaves your machine.


If you have both 2025 and 2026
------------------------------

Run START-HERE.bat once per version. When it asks which one to test, pick the
other year the second time, and send both reports.


If something goes wrong
-----------------------

The add-in is missing from the ribbon - the zip was probably extracted while
still blocked. Delete the extracted folder, unblock the zip as in step 1, and
extract again, then run START-HERE.bat once more.

Inventor is already open and it keeps saying so - close Inventor, including
any window you may have minimised, then press Enter.

You want to run only the checks again, later - start Inventor and double-click
test\run-tests.bat instead. It skips the install and the manual step.

You want it gone - close Inventor and delete this folder:

  %APPDATA%\Autodesk\ApplicationPlugins\ModeledThreads.bundle

After that Inventor will not load it again.
